## 🧬 Features

### 1. DNA Sequence Analysis

Analyze a DNA sequence to get:

- Sequence length
- Complementary strand
- Reverse complement

### 2. DNA Composition

Calculate:

- Adenine (A) percentage
- Thymine (T) percentage
- Guanine (G) percentage
- Cytosine (C) percentage
- GC content

### 3. DNA to RNA Transcription
